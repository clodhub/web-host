# Web host

The web-host component at version 0.12.0 provides com.clodhub/web-shell version 1.0.0 to an illustrative application consumer, which in turn supplies com.clodhub/theme version 1.0.0. The 2 arrows each run from a named output to a required input of the same type and version. Setting values shown are placeholders and secrets appear only as references.
